# PID 掉电保存实施计划

目标：菜单手动保存左右轮六项已生效 PID；重启自动恢复。

方案：外部 W25Q 引脚与编码器/电机冲突，采用内部 Flash S6/S7 双区追加日志；程序链接范围限制在前 256 KiB。记录包含版本、序号、六个 float、CRC32 和最后写入的提交标记。半写记录跳过，跨区先保留旧区，写完并校验后才报告成功。参数不变时不写 Flash。无有效记录使用编译默认值。

交互：左右 PID 二级菜单各增加 Save parameters（保存两轮）。Kp/Ki/Kd 的 OK 仍仅应用到 RAM。保存页显示默认/已加载/已保存/失败和是否有未保存修改。仅 STOP 且轮速低于 2 RPM 可保存；主循环执行慢速 Flash 操作，中断期间锁止运动并丢弃通信积压，结束后重建时间与编码器基准。
